# Weinberg-App – Releases

Fertige, signierte Versionen der **Weinberg-App** für Android: ein Jahres-Zeitstrahl für den eigenen kleinen Weinberg –
Aufgaben je Monat, abhaken, festhalten (Fotos, Notizen, Spritzungen, Oechsle, Lese), sichern als ZIP.

Privates, nicht-kommerzielles Projekt für Familie und Freunde. Kein Play Store, kein Konto, keine Werbung –
alle Daten bleiben auf dem Handy.

## Installieren

1. Unter **[Releases](../../releases/latest)** die Datei `weinberg-X.Y.Z.apk` auf dem Handy herunterladen.
2. Öffnen und installieren. Android fragt einmalig, ob der Browser Apps installieren darf („Diese Quelle zulassen“).
3. Spätere Versionen zeigt die App selbst an (Einstellungen → App-Version). Eure Daten bleiben beim Update erhalten.
